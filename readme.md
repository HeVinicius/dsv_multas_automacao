Olá, está é uma automação com objetivo de clarear a vida de quem utiliza o sistema de consulta de infrações DSV Digital em São Paulo

todo o projeto foi desenvolvido para um cenário único, mas acredito que seja eficaz em diferentes maquina, a final, estou rodando via Google Colab.

Projeto de automação RPA utilizando as ferramentas: Python, Selenium, Pandas, OpenPyXL e Excel
Ambiente: Google colab e Google sheets

Peço que se atentem aos comentários realizados ao longo do main.py, lá contem informações para as variáveis de cada user

Bom uso!
